# 商品导入停用重复商品处理设计

## 目标

商品 Excel 导入时，如果导入行的名称、规格、单位与系统中一条停用商品完全一致，则忽略该行；若匹配的是启用商品，保持现有校验与导入行为不变。

## 处理流程

1. `ProductServiceImpl#importExcel` 在现有校验前，从导入数据收集非空商品名称。
2. 一次性查询这些名称对应的停用商品，并按“名称 + 规格 + 单位”生成匹配键。
3. 从本次待处理导入列表中移除匹配停用商品的行。
4. 对剩余行继续执行当前 `check`、构建商品、批量新增/更新及单位同步流程。

匹配使用现有键构造规则：名称、规格和单位均先去除首尾空白，再以三元组精确比较。

## 边界与错误处理

- 被忽略的行不进行其他字段校验，不生成编号，不新增或更新任何商品数据。
- 全部导入行均被忽略时，导入正常完成，不产生数据写入。
- 名称、规格、单位匹配启用商品时，继续使用现有重复检查与更新逻辑。
- 未匹配停用商品的行，所有既有错误提示与事务行为保持不变。

## 前端提示

商品导入弹窗的提示文案增加：`名称+规格+单位与已停用商品重复时，该行将被忽略。`

## 测试

- 停用商品匹配行会被过滤，且不会进入持久化批次。
- 启用商品匹配行保留现有处理行为。
- 有效行与停用匹配行混合导入时，仅有效行会写入。
