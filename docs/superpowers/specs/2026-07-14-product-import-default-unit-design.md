# 商品 Excel 导入补齐主单位规格

## 目标

商品 Excel 导入新增或更新 `base_data_product` 后，为尚无商品单位配置的商品补齐一条主单位记录，确保后续按“商品 + 单位”匹配的业务可用。

## 范围

- 修改 `ProductServiceImpl#importExcel` 的持久化后处理。
- 不修改 Excel 模板，不支持通过 Excel 配置多单位或换算率。
- 不变更已有商品的多单位配置。

## 数据流

1. `importExcel` 完成商品新增和更新批量写入。
2. 收集本次实际持久化的商品记录。
3. 按商品 ID 批量查询 `base_data_product_unit`。
4. 仅为查询不到任何单位记录的商品创建默认单位。
5. 根据商品的 `unit`（单位字典 ID）获取单位名称，批量写入商品单位表。

默认记录字段：

- `productId`：商品 ID。
- `unitName`：单位字典名称。
- `conversionRate`：`1`。
- `baseUnit`：`true`。
- `available`：`true`。
- `sortNo`：`0`。

## 约束与异常

- 已有任意 `base_data_product_unit` 记录的商品不做删除、更新或新增，保留人工配置的多单位和换算率。
- 商品主单位为空或单位字典不存在时，不生成无效单位记录；该情况沿用导入现有的单位校验逻辑。
- 单位补齐与商品导入处于同一 Service 事务，任一步失败均整体回滚。

## 测试

- 新增商品导入后创建一条换算率为 `1` 的主单位。
- 更新商品且缺失单位配置时创建默认主单位。
- 更新商品且已有多单位时不覆盖、不重复插入。
- 单位不存在时导入失败，且不产生商品单位记录。
