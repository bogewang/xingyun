# 采购入库与销售出库询价商品标识展示设计

## 目标

在采购收货（采购入库）和销售出库的商品选择、批量添加、明细表、单据查看、明细查询和明细导出中展示“是否询价商品”。

## 数据来源

复用商品主数据的 `inquiryProduct` 字段（`true` 为“是”，`false` 或空值为“否”）。不在采购收货或销售出库单据明细中冗余保存该字段；后端查询、详情及导出时通过商品 ID 关联商品主数据获取。

## 后端范围

- 采购收货、销售出库的商品选择数据补充 `inquiryProduct`。
- 两类单据的详情和明细查询 DTO/BO 补充 `inquiryProduct`，并在 Mapper 查询中从商品表返回该字段。
- 两类单据的明细导出模型增加“是否询价商品”列，统一导出为“是”或“否”。

## 前端范围

- 采购收货、销售出库的新增和修改页面：商品联想弹窗及批量添加商品弹窗新增“是否询价商品”列。
- 两类单据的新增/修改明细表、查看页和明细查询列表新增该列。
- 页面内统一显示规则：`true` 显示绿色“是”；`false`、`null` 或 `undefined` 显示红色“否”。
- 导出任务由后端生成，前端不额外转换字段。

## 错误处理与兼容性

- 历史数据或接口字段缺失时按“否”处理，避免空白显示。
- 不修改创建、修改单据的入参，也不改变单据保存逻辑。

## 验证

- 后端测试覆盖采购收货和销售出库的明细查询/导出中询价标识的映射与“是/否”格式化。
- 前端测试覆盖红绿文本渲染与批量添加商品弹窗列定义。
- 运行相关前端测试、前端类型/代码检查和后端模块编译。
